**Regent FX Omnistar**

**Warning: If you find your save is lost after installing the mod, this is normal and it is due to the game itself. You can subscribe to other save repair mods to solve the problem**

- Add star rings and special hit/cast effect according to Regent's card images.

**RitsuLib**
RitsuLib is the pre runtime library for this mod, but it is not mandatory
Mainly used to provide a mod setting interface for adjusting parameters

**Changelog**

**0.5.0**
- Added vfx to cards and abilities:[Shining Strike], [Solar Strike], [Comet], [Supermassive], and [Radiate]
- Fixed the bug where the [Pillar Of Creation] effect was also triggered when other players generated cards
  Fixed the bug where remaining stars would remain on the screen when cards like [Lunar Blast] and [Stardust] kill enemies
- It can now run on the mobile version of wsdx233, but there are still compatibility issues (missing sound effects)

**0.4.0**
- Added special effects to cards and abilities such as Resonance, Stardust, and Spectrum Shift, and remade the Particle Wall effect
- Fixed the issue of exposure retention caused by acceleration mod hijacking waiting functions such as Pippi Speed
- Fixed the issue where teammates' ability effects could be viewed abnormaly
- Transfer sound effects to FMOD.
- Support beta 0.108+
- Add on option to toggle off sounds. (Need to install RitsuLib)
